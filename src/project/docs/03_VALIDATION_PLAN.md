# V2.3 历史验证与泄漏频段归因计划（不适用于 V2.4 版本判断）

## 第一关：离线工程

- RTL逐模块综合通过。
- 可编程DDC仿真通过。
- 完整工程综合、布局布线、时序和DRC通过。
- BIT与LTX必须来自同一次实现。

## 第二关：基础硬件

- `vga_check`返回版本`0x00020600`。
- RFDC进入状态15。
- Hardware Manager识别1个JTAG AXI和4个ILA。
- 原V2.05频谱及图像捕获功能不回退。

## 第三关：原始I/Q质量

- 每次导出32768个连续地址。
- I/Q不是全零、常数或严重削顶。
- 三次相同画面采集的功率谱主结构可重复。
- 黑屏和测试画面采集期间探头与线缆不得移动。

## 第四关：频段归因

依次采集全黑、全白、16像素棋盘、水平条纹、垂直条纹，每种至少3次。候选频带必须同时满足：

1. 同一画面的重复采集频率位置稳定；
2. 棋盘或条纹相对黑屏存在稳定差值；
3. 改变图案后旁带或调制结构按预期变化；
4. 断开VGA信号或关闭显示输出后相应结构显著变化或消失；
5. 板卡自身杂散和环境信号不能满足上述内容相关性。

## 第五关：窄带成像

将通过归因的候选频率写入可编程DDC，采集至少3组I/Q帧与紧邻的黑屏参考。重复帧空间相关度达到门限后，才进行平均、漂移校正和未知图像盲测。

V2.3的目的首先是可靠确定内容相关频段。32768点原始I/Q缓存只覆盖约0.504 ms；完整帧原始I/Q与稳定场同步仍属于确认频带后的后续工程。
